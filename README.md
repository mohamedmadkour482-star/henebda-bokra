# HENEBDA BOKRA — MVP

## المتطلبات
- Node.js 18 أو أحدث
- اتصال إنترنت لتثبيت الحزم

## التشغيل على الكمبيوتر
1. فك ضغط الملف.
2. افتح المجلد في VS Code أو الطرفية.
3. نفّذ:
   `npm install`
4. ثم:
   `npm run dev`
5. افتح العنوان الذي يظهر في الطرفية، غالبًا `http://localhost:5173`.

## تجهيز نسخة النشر
نفّذ `npm run build`، ثم ارفع محتويات مجلد `dist` إلى استضافة تدعم مواقع Vite/React.

## الموجود في النسخة الحالية
- موقع عربي RTL ومتجاوب مع الهاتف والكمبيوتر.
- أقسام الخدمات والأعمال والتواصل.
- مولّد برومبتات محلي مع نسخ النتيجة.
- نموذج طلب خدمة يحفظ البيانات محليًا في المتصفح عبر localStorage.

## حدود النسخة التجريبية
- لا يوجد Backend أو تسجيل دخول أو لوحة إدارة حقيقية.
- طلبات العملاء محفوظة على نفس الجهاز والمتصفح فقط ولا تصل إليك من الإنترنت.
- مولّد البرومبتات قالب ذكي محلي وليس اتصالًا بنموذج AI خارجي.
- لا يوجد تطبيق Android مستقل بعد؛ المرحلة التالية تحويل الموقع إلى PWA ثم إضافة Backend آمن.
- لا تضع مفاتيح API السرية في كود الواجهة الأمامية.
